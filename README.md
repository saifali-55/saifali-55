Salamtak — four-sided healthcare platform for Iraq

Connects patients, doctors, pharmacies and laboratories in one system. A doctor issues a digital prescription in the room; pharmacies bid to fulfil it and deliver; laboratories return results into the patient record. Built and deployed; pre-launch.

API — NestJS on Fly.io (Frankfurt)
Data — PostgreSQL with Prisma
Mobile — two React Native apps (patient, provider), Expo
Admin — Next.js on Vercel
Auth — OTP, Iraq SMS
Security — AES-256-GCM field-level encryption on patient data, PHI minimised across every API response, Sentry with a PHI-proof redactor

Arabic-first and RTL throughout. I designed the data model and the API boundaries before writing a line of code, and every commit passes tsc --noEmit and eslint --max-warnings=0. Two independent security audits were run against the codebase before it was shown to anyone.

The repository is private. It holds patient health data, and I am not going to open-source a healthcare backend. I'm glad to walk through the architecture and the code on a call.
